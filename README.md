# Emmanuel Lead Management Portfolio — Easy Edit Edition

Professional responsive portfolio site with a single, easy-to-edit configuration section.

## Edit everything from one place
Open `index.html` and go to the bottom. Find `EASY EDIT AREA`. Replace the values in `SITE_CONFIG`:

- `email` → your email
- `linkedin` → your LinkedIn URL
- `upwork` → your Upwork URL
- `whatsapp` → your WhatsApp URL
- `profilePhoto` → your photo filename/path
- `portfolio` → project titles, descriptions, tags, screenshots and project links
- `gallery` → gallery titles and screenshot filenames

## Add your images
Put your images inside the `assets/` folder using the matching names:

- `profile-photo.jpg`
- `portfolio-01.jpg`
- `portfolio-02.jpg`
- `gallery-01.jpg`
- `gallery-02.jpg`
- `gallery-03.jpg`
- `gallery-04.jpg`

You can use PNG/WebP too; just update the filename in `SITE_CONFIG`. Missing images automatically show a professional placeholder instead of breaking the layout.

## Add your video
Replace `assets/client-video.mp4` with your video, or change the source path in the video section.

## Project links
Replace `YOUR-PROJECT-LINK-01`, etc. with a live demo, case-study page, Google Drive/Notion presentation, GitHub repository or other public project URL.

## Before publishing
Blur/remove private client information from screenshots and replace placeholder metrics with verified results only.
